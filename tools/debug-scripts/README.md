# Internal Debugging & Reverse-Engineering Scripts

Este directorio contiene herramientas auxiliares, scripts basados en Chrome DevTools Protocol (CDP), benchmarks de latencia y pruebas de renderizado DOM desarrollados durante la fase de análisis e ingeniería inversa de Google Calendar.

> **Nota**: Estos scripts son herramientas internas de investigación y diagnóstico. No forman parte del runtime de producción de la aplicación.
